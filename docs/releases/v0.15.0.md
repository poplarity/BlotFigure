# v0.15.0 — Release record

Release date: 2026-11-16 (maintainer timezone). The maintainer explicitly requested publication of the reviewed quantification and interface work. This authorises this release only.

## Scope

- Optional post-figure quantification, one explicitly chosen loading control, fixed-size per-protein ROIs with traceable local background and direct source editing.
- Live point/bar plots and PNG/SVG/CSV/JSON/Methods exports, without inferred biological independence or automatic significance tests.
- Condition-name side/alignment, source-pixel crop/ROI dimensions, and consistent editor controls/navigation. Existing five-step figure workflow, independent exposures and non-destructive figure geometry remain intact.
- Metadata/download links move to 0.15.0. Historical v0.14.0 tag and its assets are not modified.

## Scientific and platform boundaries

Use synthetic data for automated/visual checks. Suggested ROI sizes need experimental review; same figure-lane numbers do not establish sample correspondence, loading-control stability or biological independence. Eight-bit sources retain precision warnings. Optional linearity checks do not certify publication readiness. WebKit is not native Safari.app download/storage validation; desktop PowerPoint is not exercised by the native PPT file assertions.
