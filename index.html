按左边的 5 步走（每一步确认后点"下一步"，做完的步骤可以随时点开再改）

  1. 确认 Marker 图：把这次实验所有图片一次拖进来（各次曝光 + 看得见 Marker 的图：白光图，或白光 + 化学发光的复合图）。每张膜有一张标"★ Marker 图"，不对就点对的那张下面的"设为 Marker 图"；类型认错了在图片的 ⋯ 里改。怎么猜的：先看文件名（Marker / White / 白光 / Merge / 复合 → Marker 图；Chemi / ECL / 曝光 → 曝光图），看不出时看图：白光图是一大片亮的膜放在暗的托盘上。
  2. 检查膜条：Marker 图上的蓝框是找到的膜条，要刚好框住每一条膜。拖动蓝框移动，拖边、角改大小，拖上方的 ↻ 旋转，在空白处拖出一条新的，选中后 Delete 删掉（方向键微调，[ ] 转 0.1°）。
  3. 调整蛋白框：按膜条找出每个蛋白的条带，每个蛋白一个框，右边出现成图。点框选中：拖边、角改大小，拖框内部移动（可以拖到任何位置，成图里就是框住的部分），拖上方的 ↻ 或按 [ ] 微调倾斜（框会先按条带自动摆正）。缺了蛋白就"+ 添加一个蛋白框"，再到膜上点一下放下。
  4. 标 Marker：选你用的 Marker 型号（下次自动用它），右边是它的官方条带示意（橙色 = 彩色 / 加粗的参考带）。在 Marker 图上点一条 Marker 带，选它的分子量；会自动吸附到条带上（按住 Alt 不吸附）。每条膜条标 2 条以上，就能算出各行分子量，之后其余大小的位置用虚线提示，点一下就加上。
  5. 名称、泳道与导出：填蛋白名和泳道名（左边或右侧成图上点灰字，回车跳下一个），需要的话加目标条带箭头、条件、分组、改版式，然后右上角导出 PNG；"未裁切原图"放补充材料。

常见情况

  • 给某条带标分子量（目标条带，和 GelFigure 一样）：第 5 步"标注"里点"目标条带"，再在右侧成图上点那条带：箭头吸附到条带上，按第 4 步标的 Marker 自动标分子量。点箭头可以加名称（显示成"名称 (52 kDa)"）、换成 * # †（* 常用来标非特异条带）、放到左边或右边、删除。
  • Marker 刻度标错了：拖动刻度对准条带；点刻度上的数字改分子量或删除；选中后 ↑↓ 微调、Delete 删除。点某条膜条的小标签，直接放大到它。
  • 某个蛋白在这张曝光里太亮 / 太暗：在第 3 步点这一行，展开后点别的曝光（红色 = 过曝像素）；或选中这一行后拖膜图上方的"暗部 / 亮部"，只调这一行（线性调整，图注会说明），切到"整张图"则这张图的所有行一起变。
  • 某个蛋白漏了：第 3 步"+ 添加一个蛋白框"，在膜上点一下放下（大小和其他框一样），或按住拖出任意大小。
  • 泳道没对上（和 GelFigure 一样的"首尾泳道等间距"）：把框里最左、最右两条泳道线拖到泳道中心，中间的泳道会均匀排开（按住 Alt 只动这一条）；条数不对就展开这一行，改泳道数后点"首尾对齐"。边缘条带被切掉一部分：把最外侧的泳道线往外拖，泳道整体加宽。框上方数字是每一道在成图里的列（M = Marker 道，× = 不用，点数字切换）。多认了：点那根竖线后 Delete；漏了：双击框内加一道，或把框左右边拖出去；列号错位：点 ‹ ›（最左只能到第 1 列，不会推动其他行；要让这一行更靠左，把其他行往右挪）。
  • 改了前面的步骤：比如回到第 2 步改膜条，已经调好的框、名字、刻度都留在原处。
  • 保存，下次接着做："文件 → 保存项目"（Ctrl+S）把全部图片和框、名字、Marker 刻度、版式存成一个 .blotfig 文件；"文件 → 打开项目"接着做，换电脑也行。关闭页面前没保存会提醒。
  • 调整成图里各行的上下顺序：在右侧成图上按住一行的条带上下拖到想要的位置（也可以拖成图左边的膜条标签，或左侧列表里每行前面的标签）；选中一行后 Alt+↑↓ 一次挪一位。
  • 左右对齐泳道（剪过的膜，比如膜条 A 的第 4–6 道要对准膜条 B 的第 1–3 道）：在成图上把一行的条带左右拖，按列吸附；这条膜条上的各行一起动（它们共用同一套泳道），按住 Alt 只挪这一个框。最左到第 1 列为止；左边空出来的列会自动去掉。
  • 同一个蛋白在两条膜条上（膜从中间竖着剪开）：通常会自动并成一行；没有的话，在成图上把一行拖到另一行上松开，两个框按左右顺序接成连续的列。"拆开"可以撤回。
  • 两次拍摄之间膜挪动过（补过底物、膜条拿起来又放回去）：工具按白光图认出是同一张膜，把每张图对齐到同一位置（整张膜一起动，或每条膜条各自动），缩略图上标"已对齐"。不准的话点那张图的 ⋯ →"手动对齐…"：在膜图上拖动图片让条带落进框里，Shift+拖动或 [ ] 旋转，方向键微调；"不对齐"按原样使用。认错成同一张膜时，用 ⋯ 里的"移到"把图移走。
  • 只出部分泳道 / 剪掉中间一列：在第 5 步选列范围，或在逐列剪除里取消"显示"（自动留白分隔）。
  • 分子量刻度或蛋白名换到另一边：第 5 步"版式"里选左边 / 右边；条带加边框、字号、每泳道宽度在"更多版式"里。

规范（期刊图像要求）

  • 只做整图线性调整；一行只来自一张图，不在一行内拼接不同曝光或不同膜。
  • 内参应与目标蛋白在同一张膜上，工具会检查并提示。
  • 过曝条带不可定量；导出未裁切原图作为补充材料（用拍摄的原图，不做对齐或旋转，框画在条带实际所在的位置），图注提示会自动生成。

快捷键：Ctrl+Z 撤销 · 空格+拖动或右键拖动 平移 · 滚轮 缩放 · 选中行后 ↑↓ 移动框、[ ] 转 0.1°（Shift 1°）、Alt+↑↓ 调整在成图里的上下顺序、←→ 平移泳道、Alt+←→ 调间距、Delete 删除整行 · 选中竖线后 ←→ 微调、Delete 删掉这一道 · 双击框内 加一道 · 标 Marker 时选中刻度后 ↑↓ 微调、Delete 删除 · 调整膜条时选中后方向键移动、[ ] 旋转、Delete 删除 · Ctrl+S 保存项目 · Esc 取消

① 左边：一步一步来每一步看一眼、需要就改，再点"下一步"。做完的步骤变绿，可以随时点开再改；顶栏写着现在该做什么。
② 中间：在图上直接改第 2 步改膜条，第 3 步改蛋白框，第 4 步点 Marker 条带。滚轮缩放，空格或右键拖动平移。
③ 右边：成图第 3 步起出现。点灰色文字输入蛋白名、泳道名；上下拖条带排顺序，左右拖对齐泳道。
