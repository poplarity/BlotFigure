按左边的 5 步走（每一步确认后点"下一步"，做完的步骤可以随时点开再改）

  1. 确认 Marker 图：把这次实验所有图片一次拖进来（各次曝光 + 看得见 Marker 的图：白光图，或白光 + 化学发光的复合图）。每张膜有一张标"★ Marker 图"，不对就点对的那张下面的"设为 Marker 图"；类型认错了在图片的 ⋯ 里改。怎么猜的：先看文件名（Marker / White / 白光 / Merge / 复合 → Marker 图；Chemi / ECL / 曝光 → 曝光图），看不出时看图：白光图是一大片亮的膜放在暗的托盘上。
  2. 检查膜条：Marker 图上的蓝框是找到的膜条，要刚好框住每一条膜。拖动蓝框移动，拖边、角改大小，拖上方的 ↻ 旋转，在空白处拖出一条新的，选中后 Delete 删掉（方向键微调，[ ] 转 0.1°）。
  3. 调整蛋白框：按膜条找出每个蛋白的条带，每个蛋白一个框，右边出现成图。点框选中：拖边、角改大小，拖框内部移动（可以拖到任何位置，成图里就是框住的部分），拖上方的 ↻ 或按 [ ] 微调倾斜（框会先按条带自动摆正）。缺了蛋白就"+ 添加一个蛋白框"，再到膜上点一下放下。
  4. 标 Marker：选你用的 Marker 型号（下次自动用它），右边是它的官方条带示意（橙色 = 彩色 / 加粗的参考带）。在 Marker 图上点一条 Marker 带，选它的分子量；会自动吸附到条带上（按住 Alt 不吸附）。只标 1 条也能显示这个刻度；标 2 条以上才估算其他分子量，之后其余大小的位置用虚线提示，点一下就加上。
  5. 名称、泳道与导出：填蛋白名和泳道名（左边或右侧成图上点灰字，回车跳下一个），需要的话加目标条带箭头、条件、分组、改版式，然后右上角导出 PNG；"未裁切原图"放补充材料。

常见情况

  • 一张 WB 图内分列：第 5 步点「多列排版」，每列分别填泳道、范围、条件和标题（顶端或底端）。把区域拖到另一列，或在名称旁 ⋯ 中选「移到排版列」；曝光、亮度仍各自独立。「列设置」可调间距、按行对齐、复制标签；空列不导出。
  • Marker 字号和显示：第 4 步可设全局字号。点成图的 Marker 数字，或蛋白名旁 ⋯，可单独设该区域字号、隐藏或恢复数字。隐藏数字不删除校准点。
  • 条件表和侧边标注：第 5 步粘贴从 Excel 复制的表格（第一格条件名，后面对应显示的泳道；保留空格），选追加或替换本列。Shift+点击成图格子可输入任意值。行旁括号支持竖排文字和直线样式。
  • 给某条带标分子量（目标条带，和 GelFigure 一样）：第 5 步"标注"里点"目标条带"，再在右侧成图上点那条带：箭头吸附到条带上，按第 4 步标的 Marker 自动标分子量。点箭头可以加名称（显示成"名称 (52 kDa)"）、换成 * # †（* 常用来标非特异条带）、放到左边或右边、删除。
  • IP / Input 分组、泛素化拖尾（行旁括号，和 GelFigure 一样）：第 5 步"标注"里点"行旁括号"，在右侧成图上沿着行上下拖：盖住几行就是一组（如 IP: Flag 的两行、Input 的三行），在一行里拖一段就标出这一段（如 (Ub)n 拖尾）；在一行上点一下 = 盖住整行。两端靠近行边时自动对齐（按住 Alt 不吸附）。松开后输入文字（↵ 换行），可以放左边或右边、单独设字号；点成图上的括号再改。
  • 文字里的 *：*斜体* 写成两个星号夹住（如 *p*-ERK）；单个的 *（如 WT*、K48R*）照原样显示。
  • Marker 刻度标错了：拖动刻度对准条带；点刻度上的数字改分子量或删除；选中后 ↑↓ 微调、Delete 删除。点某条膜条的小标签，直接放大到它。
  • 某个蛋白在这张曝光里太亮 / 太暗：在第 3 步点这一行，展开后点别的曝光（红色 = 过曝像素）；或选中这一行后拖膜图上方的"暗部 / 亮部"，只调这一行（线性调整，图注会说明），明确选择"高级：整张曝光"则这张图的所有行一起变。
  • 某个蛋白漏了：第 3 步"+ 添加一个蛋白框"，在膜上点一下放下（大小和其他框一样），或按住拖出任意大小。
  • 泳道没对上（和 GelFigure 一样的"首尾泳道等间距"）：把框里最左、最右两条泳道线拖到泳道中心，中间的泳道会均匀排开（按住 Alt 只动这一条）；条数不对就展开这一行，直接改泳道数（立即生效）。边缘条带被切掉一部分：把最外侧的泳道线往外拖，泳道整体加宽。框上方数字是每一道在成图里的列（M = Marker 道，× = 不用，点数字切换）。多认了：点那根竖线后 Delete；漏了：双击框内加一道，或把框左右边拖出去；列号错位：点 ‹ ›（最左只能到第 1 列，不会推动其他行；要让这一行更靠左，把其他行往右挪）。
  • 改了前面的步骤：比如回到第 2 步改膜条，已经调好的框、名字、刻度都留在原处。
  • 保存，下次接着做："文件 → 保存项目"（Ctrl+S）把全部图片和框、名字、Marker 刻度、版式存成一个 .blotfig 文件；"文件 → 打开项目"接着做，换电脑也行。刷新后开始页会提供自动保存的草稿；关闭页面前没保存会提醒。
  • 调整成图里各行的上下顺序：在右侧成图上按住一行的条带上下拖到想要的位置（也可以拖成图左边的膜条标签，或左侧列表里每行前面的标签）；选中一行后 Alt+↑↓ 一次挪一位。
  • 左右对齐泳道（剪过的膜，比如膜条 A 的第 4–6 道要对准膜条 B 的第 1–3 道）：在成图上把一行的条带左右拖，按列吸附；只移动你拖的蛋白框，同膜上的其他框不受影响。最左到第 1 列为止；左边空出来的列会自动去掉。
  • 区域各自独立：每个蛋白区域分别选择曝光、调整亮度；上下拖动只排序，落在另一行上也不会合并。旧项目已合并的区域，在第 3 步点"解除绑定，分别编辑"；也可点"全部解除绑定"。
  • 两次拍摄之间膜挪动过（补过底物、膜条拿起来又放回去）：工具按白光图认出是同一张膜，把每张图对齐到同一位置（整张膜一起动，或每条膜条各自动），缩略图上标"已对齐"。不准的话点那张图的 ⋯ →"手动对齐…"：在膜图上拖动图片让条带落进框里，Shift+拖动或 [ ] 旋转，方向键微调；"不对齐"按原样使用。分组错了，在第 1 步把缩略图拖到正确膜组；可多选一起拖动。
  • 只出部分泳道 / 剪掉中间一列：在第 5 步选列范围，或在逐列剪除里取消"显示"（自动留白分隔）。
  • 分子量刻度或蛋白名换到另一边：第 5 步"版式"里选左边 / 右边；条带加边框、字号、每泳道宽度在"更多版式"里；按期刊栏宽可以直接设成图总宽。
  • 导出前：导出前检查会列出没填名字的蛋白、过曝的行、小于 5 pt 的字、太细的线、低于 300 dpi 的有效分辨率、超过双栏宽度等问题，能改的带一键修正（可在导出菜单里关闭）。

规范（期刊图像要求）

  • 只做整图线性调整；一行只来自一张图，不在一行内拼接不同曝光或不同膜。
  • 内参应与目标蛋白在同一张膜上，工具会检查并提示。
  • 过曝条带不可定量；导出未裁切原图作为补充材料（用拍摄的原图，不做对齐或旋转，框画在条带实际所在的位置），图注提示会自动生成。
