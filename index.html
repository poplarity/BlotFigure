三步出图

  1. 拖入图片：一次实验的全部曝光 + Marker 白光图。工具自动归膜、找出每个蛋白的条带、挑最合适的曝光。
  2. 左边逐步检查：Marker 型号和刻度 → 每个蛋白的框和曝光 → 泳道名。哪里不对，就在中间的膜上直接拖动修改。
  3. 右边就是成图：点文字改名，拖条带排版，右上角导出。

最快的出图方式

  1. 把这次实验所有图片一次拖进来：每张膜的各个曝光 + Marker 白光图（iBright 的 Chemi 与 Marker 通道）。
  2. 工具自动归膜、分出各条膜条、找出每个蛋白的条带（每个蛋白一个框，泳道只在框里识别）、每行挑最清楚又不过曝的曝光（★）、读出 Marker 条带。
  3. 左边第 2 步 Marker：选你用的 Marker 型号（只需选一次，下次自动用它）；点"在白光图上核对 / 标注 Marker"——自动读出的刻度只是建议，不对就拖到对准条带，都对就点"全部确认"。
  4. 在右侧成图上点灰色的"蛋白名"和泳道号输入名称（回车跳下一个）。
  5. 右上角导出 PNG；"未裁切原图"放补充材料。

常见情况

  • 分子量不对：先在左边"Marker"里确认型号。刻度对不上 Marker 带：点"在白光图上核对 / 标注 Marker"（或点某条膜条的小标签，直接放大到它的 Marker 道），膜上显示白光图和每条膜条的 Marker 刻度——拖动刻度对准条带（会自动吸附到条带上，按住 Alt 不吸附），点空白处加一条刻度并选分子量，点刻度上的数字改分子量或删除，选中后 ↑↓ 微调、Delete 删除。每条膜条有 2 条刻度就能算出各行分子量；标过或确认过的膜条，成图左侧只画这些刻度。"全部恢复自动"丢掉手动标的和确认过的刻度。
  • 某个蛋白在这张曝光里太亮 / 太暗：在左边点这一行，展开后点别的曝光，红色 = 过曝像素。每张图只做整图线性调整，同一张图的所有行一起变。
  • 某个蛋白漏了，或没曝出来：点"在膜上框选添加"，在膜上拖一个框把它框住（只按框里的条带识别泳道）；没曝出来的就"按分子量添加"一行，再换长曝光。
  • 框的范围不合适：在中间的膜上点框选中这一行，拖框的边或四角自由缩放，框里的泳道跟着增减；拖框内部移动整个框（按住 Shift 同时上下移动这一行在各条膜条上的框）。
  • 泳道没对上：泳道只在每个框里识别，框里的竖线就是泳道，上方数字是它在成图里的列（M = Marker 道，× = 不用，点数字切换）。多认了：点那根竖线后按 Delete；漏了：双击框内加一道，或把框边拖过去；位置偏了：拖动竖线，或选中框后 ←→ 平移、Alt+←→ 调间距；整个框都不对：在左边展开这一行，点"重新识别"或"均分 N 道"；列号错位：点 ‹ ›。
  • 图片类型认错了（白光图当成了曝光图等）：点图片右上角的 ⋯ 改类型。已经调好的框都保持不动，只更新分子量和对齐。
  • 调整成图里各行的上下顺序：在右侧成图上按住一行的条带上下拖到想要的位置（也可以拖成图左边的膜条标签，或左侧列表里每行前面的标签）；选中一行后 Alt+↑↓ 一次挪一位。
  • 左右对齐泳道（剪过的膜，比如膜条 A 的第 4–6 道要对准膜条 B 的第 1–3 道）：在成图上把一行的条带左右拖，按列吸附；这条膜条上的各行一起动（它们共用同一套泳道），按住 Alt 只挪这一个框。拖过第 1 列时左边自动补列，泳道名跟着挪。
  • 同一个蛋白在两条膜条上（膜从中间竖着剪开）：通常会自动并成一行；没有的话，在成图上把一行拖到另一行上松开，两个框按左右顺序接成连续的列。"拆开"可以撤回。
  • 两次拍摄之间膜挪动过（补过底物、膜条拿起来又放回去）：工具按白光图认出是同一张膜，把每张图对齐到同一位置（整张膜一起动，或每条膜条各自动），缩略图上标"已对齐"。不准的话点那张图的 ⋯ →"手动对齐…"：在膜图上拖动图片让条带落进框里，Shift+拖动或 [ ] 旋转，方向键微调；"不对齐"按原样使用。认错成同一张膜时，用 ⋯ 里的"移到"把图移走。
  • 只出部分泳道 / 剪掉中间一列：在"泳道"里选范围，或在逐列剪除里取消"显示"（自动留白分隔）。
  • 条带要加边框：在"版式"里勾选"条带加边框"。

规范（期刊图像要求）

  • 只做整图线性调整；一行只来自一张图，不在一行内拼接不同曝光或不同膜。
  • 内参应与目标蛋白在同一张膜上，工具会检查并提示。
  • 过曝条带不可定量；导出未裁切原图作为补充材料（用拍摄的原图，不做对齐或旋转，框画在条带实际所在的位置），图注提示会自动生成。

快捷键：Ctrl+Z 撤销 · 空格+拖动或右键拖动 平移 · 滚轮 缩放 · 选中行后 ↑↓ 移动框、Alt+↑↓ 调整在成图里的上下顺序、←→ 平移泳道、Alt+←→ 调间距、Delete 删除整行 · 选中竖线后 ←→ 微调、Delete 删掉这一道 · 双击框内 加一道 · 标 Marker 时选中刻度后 ↑↓ 微调、Delete 删除 · Esc 取消
