# BlotFigure：Western blot 作图

纯前端的离线工具：把一次实验的所有 WB 图片（每张膜的多个曝光 + Marker 白光图）一起拖进去，自动拼出一张可以投稿的 WB 图。

- 双击 `index.html`，用 Chrome、Edge 或 Safari 打开。不用安装，也不用联网，图片不会上传。
- 想先看效果：点"看看示例"。示例里有一张切成 3 条、拍了 3 个曝光的膜，加上另一张斜着放的膜。

## 自动完成的部分

| 步骤 | 做法 |
|---|---|
| 区分曝光图和 Marker 图 | 先看文件名（Chemi / Marker / 白光），再看图像特征 |
| 曝光时间 | 从文件名读取，比如 `_30s`、`_2min`、`500ms`。读不到时，按图像亮度比例估算 |
| 归到哪张膜 | 曝光图之间做相关性比对，Marker 图按膜的轮廓匹配 |
| 切开的膜条和斜放的膜 | 从 Marker 白光图里分割出每一条膜条，并测出各自的角度。没有 Marker 图时，按信号区域分别校正角度 |
| 条带行 | 每个蛋白一行，双带（如 p-ERK1/2）算作同一行。并排的膜条只有在条带高度、强度都相当时才拼成一行，避免把一条膜上的弱杂带拼进另一条膜的主带。很弱的行默认隐藏，在"图中的行"里可以打开 |
| 每行选哪个曝光（自动标记最佳条带） | 每行单独评分，不需要知道曝光时间。优先选条带内没有过曝、信号足够、背景干净的一张；只有每张都过曝时才退而选过曝最少的。推荐的那张标 ★ |
| 曝光对比 | 点某一行（或它的曝光标签），会展开该行在每张曝光里的样子，从弱到强排列。过曝像素标红，并标"过曝 / 偏弱 / 太弱"，★ 为推荐。点一张就换用它，"改用推荐"可以换回来。左侧缩略图上的彩色圆点表示哪些行用了这张曝光 |
| Ladder 型号和 kDa | 从 Marker 图找到 Ladder 条带，包括双色 Marker 里颜色浅、带宽的参考带。膜条放回原位时，按一整条连续的 Ladder 匹配，允许缺带（藏在切缝里或被切掉）。分开摆放时，各膜条共用一条迁移曲线来联合拟合。kDa 刻度画在真实的 Ladder 条带上，行的分子量在相邻条带之间插值。条带太少、定不准时不标 kDa。几种型号拟合得差不多时，请在膜卡片里手动指定（会记住） |
| 泳道 | 统一泳道间距，以 Ladder 所在泳道为第 0 道，所有行按泳道对齐 |
| 对比度 | 每张图整体做一次线性调整，背景保留浅灰 |

## 需要你操作的部分

在右侧成图上点灰色的"蛋白名"和"泳道号"直接输入，回车跳到下一个。然后导出。

## 内置的期刊规范检查

- 一行只取自一张图，不会在一行内拼接不同曝光或不同的膜。
- 剪掉的泳道在所有行同步剪掉，并留白分隔。
- 内参不在同一张膜上、选用的曝光有过曝、没有 Marker 图，都会提示。
- 自动生成图注文字：注明不同膜、反色、Ladder 型号和各行的曝光时间。
- "未裁切原图"导出：每张用到的曝光图和 Marker 图，都标出裁切框、泳道号（剪掉的泳道标 X）和蛋白名。
- 灰度定量 CSV：用成图中所选的曝光，计算条带体积减去局部背景，归一化到同一张膜上的内参，过曝的值会标 SAT。

```
js/wbapp.js       状态、撤销、行/泳道/曝光逻辑、规范检查
js/wbrender.js    排版成 SVG
js/wbview.js      中间的膜图交互
js/wbui.js        面板、成图上直接编辑、导出
js/wbdemo.js      合成示例膜
js/tiff.js engine.js export.js   与 GelFigure 共用
test/engine.html  算法自测（合成膜，带真值对照）
```
