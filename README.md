# BlotFigure：Western blot 作图

纯前端的离线工具：把一次实验的所有 WB 图片（每张膜的多个曝光 + Marker 白光图）一起拖进去，自动拼出一张可以投稿的 WB 图。

- 双击 `index.html`，用 Chrome、Edge 或 Safari 打开。不用安装，也不用联网，图片不会上传。
- 想先看效果：点"看看示例"。示例里有一张切成 3 条、拍了 3 个曝光的膜，加上另一张斜着放的膜。

## 自动完成的部分

| 步骤 | 做法 |
|---|---|
| 区分曝光图和 Marker 图 | 先看文件名（Chemi / Marker / 白光），再看图像特征 |
| 曝光时间 | 从文件名读取，比如 `_30s`、`_2min`、`500ms`。读不到时，按图像亮度比例估算 |
| 归到哪张膜 | 曝光图之间做相关性比对，Marker 图按膜的轮廓匹配 |
| 拍摄之间膜挪动过 | 同一张膜两次拍摄之间常会挪动（补底物、膜条拿起来又放回去），图里膜的位置就不一样。白光图在平移、旋转之后能对上的（膜条各自放回去的，每条膜条分别对得上也算），认作同一张膜（也包括后来再添加的图）。每张图都对齐到大多数图所在的位置：白光图按膜的边缘和 Ladder 对齐；曝光图按条带两两对齐（每张和最像它的那张比），再落到同一次拍摄的白光图的位置上；膜条各自放回去的，每条膜条单独对齐。成图、换曝光、定量都用对齐后的图；未裁切原图用拍摄的原图。只有曝光图、没有白光图的不会自动并成一张膜（不同的膜做同样的蛋白，条带也一样） |
| 切开的膜条和斜放的膜 | 从 Marker 白光图里分割出每一条膜条，并测出各自的角度。没有 Marker 图时，按信号区域分别校正角度 |
| 条带行 | 每个蛋白一行，双带（如 p-ERK1/2）算作同一行。并排的膜条只有在条带高度、强度都相当时才拼成一行，避免把一条膜上的弱杂带拼进另一条膜的主带。很弱的行默认隐藏，在左侧"蛋白"列表里可以打开（● / ◌） |
| 每行选哪个曝光（自动标记最佳条带） | 每行单独评分，不需要知道曝光时间。优先选条带内没有过曝、信号足够、背景干净的一张；只有每张都过曝时才退而选过曝最少的。推荐的那张标 ★ |
| 曝光对比 | 点某一行（或它的曝光标签），会展开该行在每张曝光里的样子，从弱到强排列。过曝像素标红，并标"过曝 / 偏弱 / 太弱"，★ 为推荐。点一张就换用它，"改用推荐"可以换回来。展开左侧的图片时，缩略图上的彩色圆点表示哪些行用了这张曝光 |
| Ladder 型号和 kDa | 从 Marker 白光图找到 Ladder 条带，包括双色 Marker 里颜色浅、带宽的参考带。找 Ladder 道时对照曝光图：白光图里有带、曝光图里同一位置也有带的，多半是上样很多的样品道（发黑），只算很小的分量；只有白光图里有带的才像 Marker 道（Marker 道在曝光图里也有带时不会被排除）。曝光图里有条带的地方也不会被当成膜条之间的切缝。膜条放回原位时，按一整条连续的 Ladder 匹配，允许缺带（藏在切缝里或被切掉）。分开摆放时，各膜条共用一条迁移曲线来联合拟合。kDa 刻度画在真实的 Ladder 条带上，行的分子量在相邻条带之间插值。条带太少、定不准时不标 kDa。Marker 型号在左侧第 2 步选一次就记住，以后新载入的膜默认用它；没选过时按条带猜一个，标"请确认"。自动读出的刻度只是建议，标"待核对" |
| 泳道 | 每个蛋白一个框，每个框有自己的泳道（框里的竖线）。开始时按整张膜各行的条带定出泳道，框只框住成图要用的那几道（膜条边上多出来的杂斑不算）。"框内重新识别"只看框里的像素：泳道间距取膜上各行一致的间距，框里的条带比这个间距还宽时才改用框自己的；噪点、一条带的两个边缘都不会被认成多出来的泳道。泳道之间没有条带的空位也算一道，Marker 白光图上 Ladder 所在的那一道标 M |
| 泳道放在成图第几列 | 先自动猜：膜条放回原位、泳道和 Ladder 位置都对得上时，按位置对齐；同一个蛋白跨两条并排的膜条时，右边那个框接着左边编号；其余从第 1 列开始。框上方的数字就是每一道在成图里的列，猜错了点 ‹ › 挪 |
| 对比度 | 每张图整体做一次线性调整，背景保留浅灰。拉伸上限按像素噪声定，不会把拖尾当成噪声而把强带压成灰色 |

## 需要你操作的部分

左侧按步骤走，顶栏写着下一步做什么（点它直接跳过去），做完的步骤前面变成绿色的 ✓：

1. **图片与膜**：一般不用管。"查看 / 修改图片"展开缩略图，认错了类型、分错了膜时在图片的 ⋯ 里改。
2. **Marker 与分子量**：选你用的 Marker 型号（只需一次）；点"在白光图上核对 / 标注 Marker"看一眼自动读出的刻度，不对就拖到对准条带，都对就点"全部确认"。
3. **蛋白**：在右侧成图上点灰色的"蛋白名"（或左侧列表里的名字）直接输入，回车跳到下一个。
4. **泳道**：在成图上点灰色的泳道号输入，或一次粘贴一整行。然后导出。

第一次打开会有一个三栏的简短引导（"?" 里可以再看一遍）。

需要时：

- **框的范围不合适**：在中间膜图上点框选中这一行，拖框的四条边或四个角自由缩放：框里的泳道留在原处，框边拖过的地方按同样的间距补上泳道，拖回来就去掉；松手后框贴齐泳道（框里是什么，成图里就是什么）。拖框内部移动整个框，按住 Shift 只上下移动这一行在各条膜条上的框。改完框会在框里重新找条带（算分子量、挑曝光用）。
- **泳道对不上**：框里的竖线就是这一行的泳道，上方数字是它在成图里的列（M = Marker 道，× = 不用，点数字在三者之间切换）。多认了一道：点那根竖线，按 Delete；漏了：双击框内加一道，或把框边拖过去；位置偏了：拖动竖线，或选中框后 ←→ 平移、Alt+←→ 调间距。整个框都不对：在左侧"蛋白"里点这一行展开，点"重新识别泳道"（只看框里的像素），或填道数后"排布"（等间距）；"在膜上放大"把膜图放大到这一行的框。列号错位：点 ‹ ›。
- **漏掉的蛋白**：点"在膜图上框选添加"，在膜图上拖一个框把它框住，泳道和条带只按框里的像素识别。
- **调整成图里各行的上下顺序**：发表的组图常按需要的顺序排，不一定按分子量。在右侧成图上按住一行的条带上下拖，蓝线是要放的位置；也可以拖成图左边的膜条标签，或左侧"蛋白"列表里每行前面的标签；选中一行后 Alt+↑↓ 一次挪一位。
- **左右对齐泳道**：每条膜条是一个模块（自己的角度、泳道、Marker）。膜剪开过、上样顺序错开时（比如膜条 A 的第 4–6 道要对准膜条 B 的第 1–3 道），在成图上把这条膜条的一行左右拖，按列吸附：这条膜条上的各行一起动（它们共用同一套泳道），按住 Alt 只挪这一个框。拖过第 1 列时左边自动补列，泳道名、条件和分组跟着挪。
- **一个蛋白跨两条膜条**（膜从中间竖着剪开，两半没有放回原位）：并排、条带高度相当的会自动并成一行。没有的话，在成图上把一行拖到另一行上，出现虚线框时松开，两个框按左右顺序接成连续的列，接缝处自动留白；左边的框增减泳道时，右边的框跟着挪。"拆开"可以撤回。上下叠放、泳道相同的膜条（不同的蛋白）不能并进同一行，同一条膜条上的两个蛋白也不行。
- **膜的位置没对齐**：对齐过的图在缩略图上标"已对齐"（其他图对齐到的那张标"基准"），⋯ 菜单里写着它旋转、平移了多少。不准的话点"手动对齐…"：膜图上显示拍摄的原图和这张膜的框、膜条虚线，拖动图片让条带落进框里，Shift+拖动或 [ ] 旋转（Shift 加大步长），方向键微调，"完成"结束；"自动对齐"重新算，"不对齐"按原样使用。认错成同一张膜的，用"移到"把图移到另一张膜或新的一张膜（会对齐到那张膜上）。
- **Marker 刻度不对 / 没识别出来**：左侧第 2 步点"在白光图上核对 / 标注 Marker"（或点某条膜条的小标签，直接放大到它的 Marker 道）。膜图切到白光图，每条膜条的 Marker 道标成黄色，刻度画在道上：直接拖刻度对准条带（自动吸附到白光图上最近的深色带，按住 Alt 不吸附）；在 Marker 道上点一下加一条，选它的分子量（按 Marker 型号列出，推荐的高亮，回车即选）；虚线的刻度是按已标的推算出来的位置，点一下就加上；点刻度上的数字改分子量或删除；选中后 ↑↓ 微调、Delete 删除；右键或中键拖动平移。都对了点"全部确认"。每条膜条单独标，有 2 条刻度就能算出各行分子量，成图左侧只画这些刻度。标过或确认过的膜条，以后重新分析（比如改图片类型）都保持不变；"全部恢复自动"丢掉它们重来。
- **图片类型认错了**（白光图当成了曝光图等）：点"查看 / 修改图片"，在图片右上角的 ⋯ 里改类型。已经调好的框、行的顺序和名字都保持不变，只更新分子量和对齐；膜条上的字母也不变。只有点膜卡片上的"重新识别"才按图片从头识别所有行。
- **条带加边框**：在"版式"里勾选"条带加边框"，每块连续的条带图外画一圈细框（线宽同其他线条）。

## 内置的期刊规范检查

- 一行只取自一张图，不会在一行内拼接不同曝光或不同的膜。
- 剪掉的泳道在所有行同步剪掉，并留白分隔；成图里相邻两列只要在膜上不相邻（中间去掉了 Marker 道、或来自不同膜条），就留白分隔。
- 内参不在同一张膜上、选用的曝光有过曝、没有 Marker 图，都会提示。
- 自动生成图注文字：注明不同膜、反色、Ladder 型号和各行的曝光时间。
- "未裁切原图"导出：每张用到的曝光图和 Marker 图（拍摄的原图，不做对齐或旋转），都标出每个框、框里每一道对应的成图列号（没用上的标 X，Marker 道标 M）和蛋白名，框画在条带在这张原图里的实际位置。
- 灰度定量 CSV：用成图中所选的曝光，计算条带体积减去局部背景，归一化到同一张膜上的内参，过曝的值会标 SAT。
